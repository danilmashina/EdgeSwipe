# EdgeSwipe

Лёгкое приложение для MacBook: управляйте яркостью, громкостью и музыкой одним пальцем по краям встроенного трекпада.

![Выбор рабочих зон](Assets/edge-area-preview.svg)

## Возможности

- Левый край — яркость встроенного дисплея.
- Правый край — системная громкость.
- Свайп вверх увеличивает значение, вниз уменьшает.
- Нижний край: слева направо — следующий трек, справа налево — предыдущий.
- Три режима зон для яркости и громкости: весь край, верхняя или нижняя половина тачпада.
- Работает в фоне; управление и выбор зоны — из меню в строке меню macOS.
- Без сторонних зависимостей.

## Требования

- macOS 13 Ventura или новее;
- MacBook со встроенным трекпадом;
- разрешения **Универсальный доступ** и **Мониторинг ввода**.

Проверено на MacBook Pro с M1 Pro.

## Установка из GitHub

1. Скачайте `EdgeSwipe.dmg` из [Releases](../../releases).
2. Откройте образ и перетащите `EdgeSwipe.app` в папку «Программы».
3. Откройте `EdgeSwipe` из папки «Программы». При первом запуске macOS может сообщить, что приложение от неустановленного разработчика.
4. Откройте **Системные настройки → Конфиденциальность и безопасность**, прокрутите страницу вниз и нажмите **Открыть всё равно** для EdgeSwipe. Затем подтвердите запуск.
5. В меню EdgeSwipe нажмите строку `Accessibility: разрешить` и включите EdgeSwipe в разделе **Универсальный доступ**.
6. В разделе **Мониторинг ввода** также включите EdgeSwipe.

После выдачи разрешений закройте и снова откройте EdgeSwipe из папки «Программы». Приложение начнёт получать касания. Его можно выключить, выбрать рабочую область или включить автозапуск из меню в строке меню.

> EdgeSwipe пока распространяется без Developer ID-подписи, поэтому шаг «Открыть всё равно» нужен только при первой установке. Никогда не обходите системное предупреждение для файлов из неизвестных источников — используйте только страницу Releases этого репозитория.

## Как пользоваться

| Жест | Действие |
| --- | --- |
| Вверх по левому краю | Увеличить яркость |
| Вниз по левому краю | Уменьшить яркость |
| Вверх по правому краю | Увеличить громкость |
| Вниз по правому краю | Уменьшить громкость |
| Нижний край слева направо | Следующий трек |
| Нижний край справа налево | Предыдущий трек |

### Рабочая область краёв

В меню можно выбрать, где будут работать левый и правый края:

- **Весь край** — по всей высоте тачпада;
- **Верх** — только верхняя половина;
- **Низ** — только нижняя половина.

Выбранный вариант сохраняется между запусками.

## Сборка из исходников

Для сборки нужен Xcode и Command Line Tools:

```sh
./build-installer.sh
```

Готовый образ появится в корне проекта: `EdgeSwipe.dmg`.

## Важно

EdgeSwipe использует системный фреймворк macOS для чтения касаний встроенного трекпада. Это приложение предназначено для личного использования и не распространяется через Mac App Store. Поддерживаются только встроенный дисплей и встроенный трекпад MacBook; внешние мониторы и Magic Trackpad пока не поддерживаются.
